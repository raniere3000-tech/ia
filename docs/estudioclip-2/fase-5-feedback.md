# F5.03 — feedback específico do Coordenador

A área Coordenador → Aprendizado recebe feedback para A1 (gancho), A3 (roteiro),
A5 (efeitos aplicados), A6 (seleção de capa), A2 (hora UTC) e A4 (critérios).
Cada grupo preserva canal, rede e vertente; não combina grupos para completar
amostra. Comparações precisam do mínimo existente de vídeos em dois valores.

Cada recomendação traz snapshots e estatística descritiva. Mesmo com amostra,
só propõe hipótese para teste controlado, sem afirmar causalidade. Campos não
capturados, como roteiro_sha ou criterio_qa nos legados, geram dados insuficientes;
não se deduz o roteiro pela versão atual do projeto nem se reduz a nota de QA.
Sem aplicar prompts, configurações, pesos, DNAs ou memórias automaticamente.

Três testes novos e 80 verificações do Coordenador passaram. Frontend 18 testes
e build passaram. Nenhuma consulta real a redes.
